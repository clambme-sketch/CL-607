# CL-607 Drum Machine (v1.1.0)

An interactive Web Audio API drum machine, synthesizer, and live DJ performance deck with 808, 909, and 727 kits, custom Kick Drum Designer, real-time audio effects, live sample recording, rhythmic notation score, and multiple hardware-inspired visual themes.

View your app in AI Studio: https://ai.studio/apps/c9c004a5-2e6d-4c45-b5b2-9d6d3eb32c94

## Highlights in v1.1.0

- **Quantized Pattern & A/B Switching**: Waits until the end of the current measure by default before switching pattern slots (1–4) or A/B sides (`END OF BAR` / `INSTANT` toggle in Settings).
- **Per-Instrument Mute & Solo**: Dedicated Mute and Solo controls next to every instrument volume slider (with visibility toggle in Settings).
- **Tape Stop — Pause After Stop**: Option to automatically pause playback after the tape reel brakes to a stop.
- **Themed Sunglasses Cat & Disco Ball**: Custom colorways tailored to every visual style (Default, Virtual, Domino, Color Block, Sunset, Gold Trim, and Minimal), while preserving the original cat in Classic 607.
- **High-Contrast Typography Across All Visual Themes**: Crisp legibility across both light and dark hardware themes.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
